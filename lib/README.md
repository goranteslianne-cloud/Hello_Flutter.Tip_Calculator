
# Hello Flutter: Tip Calculator

## Description
A simple Flutter Tip Calculator that calculates the tip and total bill based on the selected percentage.

## Features
- Enter bill amount
- Select 10%, 15%, or 20% tip
- Automatically calculate tip and total
- Validate invalid input
- Reset calculator
- Display amounts with two decimal places

## Technologies Used
- Flutter
- Dart
- Material 3
